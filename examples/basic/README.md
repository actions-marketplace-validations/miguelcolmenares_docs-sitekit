# Basic site

The smallest useful configuration: a name, a description, a URL and a hero.

```json
{
  "site": {
    "name": "My package",
    "description": "What it does in one sentence.",
    "url": "https://me.github.io",
    "base": "/my-package/"
  },
  "hero": {
    "title": "My package",
    "lede": "What it does, and why you would use it.",
    "primary": { "label": "Get started", "href": "/docs/" }
  }
}
```
